## Scope
Documents service for structured document storage, retrieval, and publishing.

## Open API Contract Draft
Public read surfaces under /doc/v3/api.

## App API Contract Draft
Authenticated app surfaces under /app/v3/api.

## Backend API Contract Draft
Operator surfaces under /backend/v3/api.

## Database And Storage Design
Tables use documents_ prefix: documents_document, documents_revision, documents_audit_log.

## Framework Integration
- sdkwork-web-framework for HTTP *-api surfaces
- sdkwork-database for lifecycle SPI
- sdkwork-utils for cross-language utility helpers (id, validation)
- sdkwork-discovery deferred until RPC services exist

## Runtime Topology
Documents adopts SDKWork application-http-gateway topology v2 via `specs/topology.spec.json` and `etc/topology/*.env`. See `docs/topology-standard.md`.

## SDK Generation

All SDKWork Documents HTTP SDKs MUST be generated by the canonical SDKWork generator:

```text
..\sdkwork-sdk-generator
```

The executable entrypoint is:

```text
..\sdkwork-sdk-generator\bin\sdkgen.js
```

SDK family roots:

```text
sdks/sdkwork-documents-sdk
sdks/sdkwork-documents-app-sdk
sdks/sdkwork-documents-backend-sdk
```

OpenAPI authority documents:

```text
sdks/sdkwork-documents-sdk/openapi/documents-open-api.openapi.json
sdks/sdkwork-documents-app-sdk/openapi/documents-app-api.openapi.json
sdks/sdkwork-documents-backend-sdk/openapi/documents-backend-api.openapi.json
```

Generation commands must use the canonical `sdkwork-sdk-generator` entrypoint and the SDKWork v3 profile:

```powershell
node ..\sdkwork-sdk-generator\bin\sdkgen.js generate `
  -i sdks\sdkwork-documents-sdk\openapi\documents-open-api.openapi.json `
  -o sdks\sdkwork-documents-sdk\sdkwork-documents-sdk-typescript\generated\server-openapi `
  -n DocumentsOpen `
  -t custom `
  -l typescript `
  --sdk-name sdkwork-documents-sdk `
  --package-name @sdkwork/documents-sdk `
  --api-prefix /doc/v3/api `
  --fixed-sdk-version 0.1.0 `
  --standard-profile sdkwork-v3
```

```powershell
node ..\sdkwork-sdk-generator\bin\sdkgen.js generate `
  -i sdks\sdkwork-documents-app-sdk\openapi\documents-app-api.openapi.json `
  -o sdks\sdkwork-documents-app-sdk\sdkwork-documents-app-sdk-typescript\generated\server-openapi `
  -n DocumentsApp `
  -t app `
  -l typescript `
  --sdk-name sdkwork-documents-app-sdk `
  --package-name @sdkwork/documents-app-sdk `
  --api-prefix /app/v3/api `
  --fixed-sdk-version 0.1.0 `
  --standard-profile sdkwork-v3
```

```powershell
node ..\sdkwork-sdk-generator\bin\sdkgen.js generate `
  -i sdks\sdkwork-documents-backend-sdk\openapi\documents-backend-api.openapi.json `
  -o sdks\sdkwork-documents-backend-sdk\sdkwork-documents-backend-sdk-typescript\generated\server-openapi `
  -n DocumentsBackend `
  -t backend `
  -l typescript `
  --sdk-name sdkwork-documents-backend-sdk `
  --package-name @sdkwork/documents-backend-sdk `
  --api-prefix /backend/v3/api `
  --fixed-sdk-version 0.1.0 `
  --standard-profile sdkwork-v3
```

Later Rust SDK generation uses the same generator with `-l rust`.

Generated SDK output must not be hand-edited. Each `generated/server-openapi` output root must retain the generator control plane:

- `sdkwork-sdk.json`
- `.sdkwork/sdkwork-generator-manifest.json`
- `.sdkwork/sdkwork-generator-changes.json`
- `.sdkwork/sdkwork-generator-report.json`
- `custom/` for handwritten extensions that survive regeneration

The generated package may be checked or built locally with `bin/publish-core.mjs`. Local verification can create `node_modules/`, `dist/`, and `package-lock.json` under `generated/server-openapi`; these are build artifacts, not generator-owned source artifacts, and must stay out of repository review and release source diffs.

`sdkwork-code-generator`, `openapi-generator`, `swagger-codegen`, copied generator code, local stubs, and direct edits to generated-owned files are not approved SDK generation paths for SDKWork Documents.

Use `pnpm sdk:generate` to standardize SDK families and regenerate TypeScript SDKs. Use `pnpm api:materialize` to sync `apis/` authority copies from SDK OpenAPI inputs.
