# SDKWork Documents PC

Browser/desktop app surface for SDKWork Documents.

This surface follows `APP_PC_ARCHITECTURE_SPEC.md` and consumes generated app SDK families from the repository root `sdks/` directory.

## Scripts

- `pnpm dev`: browser development entry (scaffold).
- `pnpm build`: browser bundle build (scaffold).
- `pnpm lint`: TypeScript check (scaffold).

Run repository verification from the root with `pnpm verify`.
